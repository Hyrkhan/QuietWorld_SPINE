# Character Art Prompts — NPCs & UI Hero Previews

Same master-rules + swappable-SUBJECT format as the prop prompt. Paste the whole
**MASTER PROMPT** and replace `{{SUBJECT}}` with one line from the list at the bottom.

> ⚠️ **IP note:** the style reference is *Pacifica* — use it for **style only**, never
> copy their characters, logo or designs. The subjects below are your own Verge cast.

> 🎨 **Palette canon source:** per-NPC colours below are pulled from
> [`ART_PROMPTS.md`](./ART_PROMPTS.md) and [`NPCS.md`](./NPCS.md). Those are the
> source of truth — every NPC has a **distinct non-bronze primary**. Treat the
> SUBJECT line as palette law; the master prompt's "default palette" is only a
> fallback for colours the SUBJECT doesn't name.

## MASTER PROMPT

```
Game character key-art in the stylized cel-shaded anime-MMORPG style of Grand Fantasia / Flyff / Pacifica — bold, chunky, painterly-cartoon. NOT Genshin realistic-anime (that's soft-realism), NOT flat vector art, NOT pixel art, NOT western cartoon. Single full-body character for an RPG character roster / UI preview.

VIEW RULES (critical):
- NPC subjects: calm STANDING full-body portrait, slight 3/4 turn toward the camera, semi-realistic anime proportions (~6 heads tall), holding their role prop, grounded relaxed pose.
- HERO subjects (class previews): DYNAMIC full-body ACTION pose (mid-swing / drawing a bow / casting), semi-chibi proportions (~3.5 heads tall — big head, shorter limbs, cute and heroic).
- The subject line says NPC or HERO — follow it.
- ALWAYS full body: head to feet in frame, centred, pivot at the feet. Front or 3/4 view. NO top-down, NO isometric, NO cropped close-up.

STYLE RULES:
- Bold, clean, near-black dark ink outline around the character and every sub-part (hair clumps, armor pieces, weapon, props). Confident uniform "marker" weight, no sketchy or tapered lines.
- Cel-shading with soft airbrushed gradients inside each shape: 3 values per material (base + shadow + highlight), crisp anime rendering, soft highlights — never flat dead fills, never muddy.
- Big expressive anime eyes, spiky stylized hair, a clear readable expression and silhouette.
- Subtle warm cream rim-light (#E8D4B5) just inside the outline on rounded forms (the painterly glow trick).
- Chunky, rounded, appealing proportions; friendly and heroic, NEVER grim or gothic.
- Each piece of gear reads as its own cleanly separated, fully-outlined shape (paper-doll / cutout logic).

PALETTE RULES (the Verge canon — the SUBJECT line's named colours always win):
- The SUBJECT line is palette law. If the SUBJECT names a colour for a garment ("forest-emerald coat", "indigo tabard", "pale-turquoise skin"), paint it exactly that colour. The hex defaults below only apply to materials the SUBJECT does NOT name.
- Every NPC has a DISTINCT PRIMARY COLOUR — no two share one. Treat the "bronze ring-mail + brown leather" default as a FAILURE MODE: if the SUBJECT doesn't say bronze, don't paint bronze.
- Fallback hexes (use only for unmentioned materials):
  - Leather / wood: #8A6341 base / #6B4A2E shadow / #B88F6D highlight.
  - Linen / cloth / pale-stone trim: #E8D4B5 base / #BFA783 shadow / #F6E0B5 highlight.
  - Bronze / brass fittings: #B88F6D base / #8A5F2F shadow / #E8A868 highlight.
  - Foliage / ranger green: #4A6E3A base / #2A4E1A shadow / #78A050 highlight.
  - Cloth accents: crimson #D4324B or teal #3A8E6A, warm not muddy.
- Named-colour reference (use when a SUBJECT names one of these):
  - Forest emerald #2E6E4A, honey-gold #F6C04A, sage green #6A8A5A, Reliquary indigo #2E3A7A, deep ruby/burgundy #B8324B, midnight purple #3A2A5A, pale-silver ring-mail #BFC6CE, sky-blue #AEDAE8, crimson #D4324B, ash-white #ECE8DE, bone-gray #B5B0A0, soot-black #1A1A1A, pale-turquoise skin #A8E0D4, sea-foam pearl #D4EDE4, deep ocean green #1F5F55, wheat-gold robe #D4B04A, saffron orange #E8873A, ink navy #26305A, vermillion #D4323A, mustard yellow #D4A82A, chord-sand pale-blue #B4D4E8, deep umber skin #4A2E22, tarnished gilt #B8933A, dusty rose #D4A4A4, faded velvet violet #6A4A7A.
- ONE "hero accent" per character, oversaturated, in a small spot — pale-cyan stillfire glow #5EC9FF by default (weapon trail, crystal, glowing eyes). Alternatives: honey-gold #F6C04A (noble / Reliquary), warm orange #F6A04A (fire).
- NO desaturated neutrals or muddy mid-browns UNLESS the SUBJECT explicitly calls for them (Whisper-Vendor's ash-white + charcoal is one such deliberate exception).

BACKGROUND:
- TRUE PNG transparency (alpha = 0) OR plain flat white. Do NOT draw a checkerboard/grid — that is a UI preview of transparency, not part of the image.
- The character stands alone. NO scenery, NO ground tile, NO drop shadow (the engine adds it), NO reflection, NO extra props besides what the character holds.
- Square 1:1 (or 3:4 portrait) canvas, character centred.

AVOID: top-down / isometric / 3-4 overhead view, photoreal materials, Genshin soft-realism, western cartoon, flat vector, pixel art, grimdark, heavy weathering, lens flares, anime glossy sparkle lines, extra limbs, extra fingers, bad hands, text, watermark, signature, multiple characters in one image.

SUBJECT: {{SUBJECT}}
```


## MASTER PROMPT MANGA-LIKE CHIBI STYLE
```
Create a single full-body CHIBI RPG character for a character roster / UI preview.

ART DIRECTION:
Stylized cel-shaded anime-MMORPG key-art inspired by Grand Fantasia / Flyff / Pacifica, with bold MANGA INKING: chunky, appealing forms, rich painted color inside clean shapes, thick pure-black outlines, and deliberate solid-black shadow wedges.
NOT Genshin soft-realism, photorealism, flat vector art, pixel art, or western cartoon.

If an approved character image is attached, use it ONLY as a reference for proportions, inking, and color rendering. Do not copy its face, hairstyle, outfit, accessories, or pose.

VIEW AND PROPORTIONS — CRITICAL:
- ALL characters use CHIBI proportions: approximately 3–3.5 heads tall, large expressive head, compact torso, shorter limbs, and sturdy appealing hands and feet.
- NPC: calm, grounded STANDING full-body portrait. Give each NPC a distinct, character-appropriate pose.
- HERO: dynamic full-body action pose appropriate to the class.
- ALL NPCs face toward the RIGHT side of the canvas in a slight three-quarter view. Their face and torso turn right while remaining readable to the viewer.
- Eye-level view. Entire head, hair, feet, equipment, and any halo must fit inside the canvas with clear margins.
- Center the character, with the roster pivot at the feet.
- NO top-down, overhead, isometric, or cropped framing.

MANGA INKING — DEFINING FEATURE:
- Use thick, confident PURE-BLACK outlines around the silhouette and every major separate form: hair locks, face, garments, armor, hands, footwear, and props.
- Exterior contours are strongest; internal structural lines are slightly finer but still clean and decisive.
- Where contours meet or forms overlap, fill the junction with a controlled SOLID-BLACK TRIANGULAR WEDGE or tapered ink pocket.
- Place these black wedges naturally between hair locks, under the fringe and jaw, beneath collars, at armor overlaps, finger creases, sleeve folds, belt junctions, and boot overlaps.
- These wedges must explain depth and reinforce the silhouette. They are NOT decorative triangles scattered across surfaces.
- Preserve clear separation between individual pieces of clothing and gear.
- No thin brown outlines, sketchy strokes, scratchy hatching, or indiscriminate black patches.

COLOR AND SURFACE RENDERING:
- Use three controlled tonal families per material: base, shadow, and highlight.
- Crisp cel-shaded shadow shapes with smooth, restrained painted gradients INSIDE each shape.
- Rounded, soft highlights and a subtle warm cream rim-light (#E8D4B5) just inside selected outlines.
- Rich, clean colors; neither flat dead fills nor muddy soft-realism.
- Hair must read as broad, deliberately shaped locks with coherent highlight bands following their curves.
- NO color noise, mottling, random dark streaks, grain, rough brush flecks, oily sheen, sharpening artifacts, or dirty edge halos.
- Cloth embroidery should look sewn into fabric: fine thread outlines and stitch details following folds. Do not render embroidered motifs as glossy metal objects or shaded picture icons unless explicitly requested.

INDIVIDUAL FACE DESIGN:
- Give every character a distinctive face suited to their age, ancestry, temperament, and role.
- Vary eye silhouette, upper-lid angle, lower-lid shape, eyebrow structure, nose, mouth, and facial proportions.
- Do not reuse one generic youthful anime face across the roster.
- Eyes should be expressive and deliberately drawn, with simple readable irises, strong upper-lid ink, and restrained highlights.
- Use one small intentional catchlight per eye by default. No giant glossy irises, multiple sparkle reflections, star glints, or doll-like glass eyes.
- Iris color and design may reflect ancestry when specified, while preserving the SUBJECT’s description.
- Hair should have a distinctive silhouette appropriate to the character; not everyone needs spiky hair.
- Friendly, appealing fantasy characterization. Never automatically grim, gothic, or villainous.

POSE, HANDS, AND PROPS:
- Use relaxed, anatomically coherent shoulders, elbows, wrists, and fingers.
- Human or humanlike hands have FOUR fingers plus ONE opposing thumb. Fingers have distinct joints, natural lengths, and readable separation.
- A thumb may be hidden behind a grip or body when anatomically appropriate; do not omit one of the four fingers to compensate.
- Avoid fused fingers, mitten hands, extra digits, rigid finger fans, claw poses, and sharply kinked wrists.
- If webbing is requested, add delicate membranes only between finger bases. Preserve all five digits and their distinct tips.
- Vary NPC poses across the roster. Do not automatically give everyone an outward-facing open palm.
- Use props only when specified or essential to the design. Character, clothing, posture, and expression can communicate a role without an obligatory handheld object.
- Hands must wrap naturally around held objects, with believable contact and support.
- Unheld bells, cords, chains, beads, and tassels hang downward under gravity from clear attachment points.
- Keep prop geometry consistent: no extra openings, branches, duplicated parts, or invented extensions.

PALETTE RULES — THE VERGE CANON:
- The SUBJECT line is palette law. Named colors override every fallback below.
- Give the named primary color enough visible area to dominate the design.
- Each NPC should have a distinct primary-color identity within the supplied roster.
- Do not default to bronze armor and brown leather. Bronze is used only where specified or for minor appropriate fittings.
- Fallback colors apply ONLY to materials whose colors are unspecified:
  - Leather / wood: #8A6341 base / #6B4A2E shadow / #B88F6D highlight.
  - Linen / pale-stone trim: #E8D4B5 base / #BFA783 shadow / #F6E0B5 highlight.
  - Bronze / brass fittings: #B88F6D base / #8A5F2F shadow / #E8A868 highlight.
  - Foliage / ranger green: #4A6E3A base / #2A4E1A shadow / #78A050 highlight.
  - Cloth accents: crimson #D4324B or teal #3A8E6A.

NAMED-COLOR REFERENCE:
Forest emerald #2E6E4A
Honey-gold #F6C04A
Sage green #6A8A5A
Reliquary indigo #2E3A7A
Deep ruby / burgundy #B8324B
Midnight purple #3A2A5A
Pale-silver ring-mail #BFC6CE
Sky-blue #AEDAE8
Crimson #D4324B
Ash-white #ECE8DE
Bone-gray #B5B0A0
Soot-black #1A1A1A
Pale-turquoise skin #A8E0D4
Sea-foam pearl #D4EDE4
Deep ocean green #1F5F55
Wheat-gold robe #D4B04A
Saffron orange #E8873A
Ink navy #26305A
Vermillion #D4323A
Mustard yellow #D4A82A
Chord-sand pale-blue #B4D4E8
Deep umber skin #4A2E22
Tarnished gilt #B8933A
Dusty rose #D4A4A4
Faded velvet violet #6A4A7A

ACCENTS:
- Use at most ONE concentrated saturated accent color.
- Default magical accent: pale-cyan stillfire #5EC9FF.
- Alternatives: honey-gold #F6C04A or warm fire-orange #F6A04A.
- Keep the accent small and subordinate to the character’s named palette.
- Do not invent magical effects for a nonmagical character.
- Desaturated neutrals and muddy browns are allowed only where explicitly called for or used sparingly in appropriate supporting materials.

BACKGROUND AND OUTPUT:
- TRUE transparent PNG background, alpha = 0. If transparency is unavailable, use plain flat white.
- Never draw a checkerboard or transparency-preview grid.
- Single character alone.
- No scenery, ground tile, cast/drop shadow, reflection, or unrelated props.
- Square 1:1 or 3:4 portrait canvas.
- Full silhouette and any requested effects stay inside the frame with comfortable margins.

AVOID:
Generic interchangeable anime faces, realistic-anime soft rendering, photoreal materials, flat vector fills, western cartoon styling, pixel art, grimdark, heavy weathering, noisy hair shading, lens flares, excessive sparkles, cropped feet or hair, extra limbs, incorrect fingers, text, watermark, signature, and multiple characters.

SUBJECT: {{SUBJECT}}
```

## Notes
- Keep the **MASTER PROMPT identical** across the whole cast — only swap `{{SUBJECT}}` — so NPCs read as one cast and heroes as one roster.
- **Palette discipline:** if the AI tries to repaint a named colour (e.g. renders Govrik's emerald coat as brown), re-roll with *"ignore the master palette defaults; use ONLY the colours named in the SUBJECT line"* in a negative prompt pass.
- **SDXL/Forge:** an anime/illustration checkpoint (Illustrious / Pony family) + an "RPG character" LoRA nails this best; the AVOID block doubles as your negative prompt.
- **Consistency:** render ~15 good ones, then train a LoRA on them for a locked, reusable style.
- **For in-UI cutouts:** generate on white → remove background (rembg).
- **Cross-reference:** detailed lore voice + placement coords per NPC in [`NPCS.md`](./NPCS.md); the chibi 1:1 portrait prompt family in [`ART_PROMPTS.md`](./ART_PROMPTS.md) is the companion doc for the dialogue-UI headshots (different art direction, same palette canon).
